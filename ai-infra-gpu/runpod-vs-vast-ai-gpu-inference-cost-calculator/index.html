How does API Cost Audit calculate 12-month LLM token, prompt caching, and Batch API TCO?

Our deterministic calculator separates uncached input tokens, cached prefix read tokens (90% off on Anthropic Claude 4.5, 75% off on Google Gemini 2.5, 50% off on OpenAI GPT-5/GPT-4o), and output tokens, then applies the 50% asynchronous 24-hour Batch API discount to the percentage of workloads routed through batch queues.

When does self-hosting Llama 4 or DeepSeek on H100 GPUs beat managed LLM token APIs?

A single H100 80GB GPU on RunPod ($2.69/hr), Vast.ai ($1.89/hr), or DigitalOcean GPU Droplets ($2.99/hr) costs ~$1,380 to $2,180/month and sustains ~450M–900M tokens/month via vLLM continuous batching. Once your monthly frontier API bill exceeds ~$2,000/month with steady utilization, dedicated GPU pods reduce unit token cost by 55%–78%.

Why do Voice AI agents cost $0.14–$0.24/minute in production despite $0.05/min headline pricing?

Headline orchestrator pricing (such as Vapi at $0.05/min) covers only the orchestration layer.
